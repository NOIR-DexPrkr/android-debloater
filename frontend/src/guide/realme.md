# Guía específica para realme (realme UI)

## Particularidades de realme UI

realme UI está basada en la base tecnológica de ColorOS, complementada con su propio ecosistema de marca (realme Link, comunidad y tienda).

---

## Servicios prescindibles recomendados en realme UI

1. **Ecosistema realme:**
   - `com.realme.link` (realme Link para accesorios y domótica, si no los usas).
   - `com.realme.community` (Comunidad oficial de realme).
   - `com.realme.store` (Tienda oficial realme).
2. **Promoción de contenido y publicidad:**
   - `com.glance.internet` / `com.heytap.pictorial` (Carrusel de fondos de pantalla con contenido promocional).
   - `com.heytap.market` (Mercado de apps secundario).
   - `com.heytap.themestore` (Tienda de temas de realme).
3. **Servicios de pagos y créditos:**
   - `com.finshell.wallet` (FinShell Pay / Cartera financiera).

---

## Paquetes críticos que NO debes eliminar en realme UI

| Paquete | Motivo |
|---|---|
| `com.realme.launcher` / `com.oppo.launcher` | Lanzador del sistema realme UI. |
| `com.coloros.safecenter` | Centro de seguridad y gestión de memoria. |
| `com.realme.securitycheck` | Comprobación de integridad de aplicaciones. |
